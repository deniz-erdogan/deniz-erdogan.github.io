# Deniz Erdogan - Personal Academic Website

This repository contains the source code for my personal academic website, hosted on GitHub Pages. The website showcases my academic background, research interests, publications, and contact information.

## Features

- Modern, responsive design using Bootstrap 5
- Clean and professional academic layout
- Sections for research, publications, education, and contact
- Smooth scrolling and fade-in animations
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome icons
- JavaScript (for animations and smooth scrolling)
- Google Fonts (Inter and Montserrat)

## Development

To run this website locally:

1. Clone this repository
2. Open `index.html` in your browser
